⏱️ TOKEN REFRESH LIFECYCLE

Access Token: 24 hours
Refresh Token: 18 days

Server Startup
  ↓
  Wait 5 minutes
  ↓
  Generate Access Token (valid until tomorrow)
  ↓
  Store in memory cache
  ↓
  Every 12 hours: Background job refreshes token proactively
  ↓
  On every API call: Use cached token or auto-refresh if expired
  ↓
  On graceful shutdown: Clean up resources

Critical: Every 18 days, refresh token expires and must be renewed from
Eshopbox dashboard. Update ESHOPBOX_REFRESH_TOKEN in .env and restart server.

Single Responsibility:
  • Token manager handles auth only
  • Order service handles order operations only
  • Tracking service handles tracking only
  • Each service is independently testable

Error Handling:
  • All errors are logged and reported
  • API errors don't crash the server
  • Token refresh failures don't stop the job
  • Webhook processing is non-blocking

Type Safety:
  • Full TypeScript strict mode
  • Zod validation on all inputs
  • Type-safe API responses
  • No 'any' types

Performance:
  • Token cached in memory (~1KB)
  • Tracking cached (~100 bytes/entry)
  • All API calls are async/await
  • Background job doesn't block server

Security:
  • Bearer token authentication
  • No sensitive data in logs
  • Environment variables for secrets
  • Zod validation prevents injection
